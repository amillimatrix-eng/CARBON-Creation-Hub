## 3. Define separate evidence states

The following states are not interchangeable. Report only the furthest state supported by evidence.

1. **SOURCE RETRIEVED** — fetch the exact canonical target plus parent issue/page context, material comments, linked controlling source and relevant supersessions.
2. **CONTEXT RECONSTRUCTED** — accurately relate original objective, current status, priority, current mandate/owner, hard boundaries, dependencies and unknowns. Reading a new comment without its parent record does not pass.
3. **DECISION ALIGNED** — the chosen next action fits the reconstructed context, owner mandate, current priority and constraints. Understanding a rule is not proof that the decision applies it.
4. **AUTHORIZED ACTION EXECUTED** — the requested operation actually occurred through a permitted route. A plan, attempted send, prompt edit or accepted run request is not the operation's completion receipt.
5. **OUTCOME VERIFIED** — independent evidence demonstrates the requested acceptance condition, not merely that a tool call returned success.
6. **RESULT PERSISTED AND READ BACK** — the actual consequence, remaining blocker and next action are durably saved and fetched back. Verify the resulting state as well as the target write; a comment ID proves the comment, not the truth of the context or success of the task.
7. **FRESH-CONTEXT APPLICATION VERIFIED** — an existing authorized consumer independently retrieves the controlling rule and applies it correctly to a relevant later case without requiring the Owner to repeat settled information.

No earlier state implies a later one. Useful intermediate progress must be retained without upgrading the overall task to PASS.
