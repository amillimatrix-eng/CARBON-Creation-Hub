The observed regression is not adequately described as “email volume,” “lead shortage,” “scheduler failure,” or “worker inactivity.”

The material loss is the **shape of the reasoning**.

The previously demonstrated state behaved as a broad commercial reasoning system that repeatedly connected:

**observed evidence → business/problem instance → capability or capability combination → payer/decision-maker → offer/action → external consequence → retained state → next conversion action**

The degraded state instead repeatedly collapses toward generic search formulations such as:

**find jobs / find leads / find opportunities / search prospects**

Those two modes are not equivalent.

The required recovery target is therefore not merely prior prompts, files, counts, or worker enablement.

It is the **learned relationship graph behind the prior behavior**.
