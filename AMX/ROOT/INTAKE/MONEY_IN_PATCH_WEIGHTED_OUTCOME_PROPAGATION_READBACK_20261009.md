# GOVERNANCE + BLUE STATE PROPOSAL — WEIGHTED OUTCOME PROPAGATION READBACK

**Intake ID:** ROOT-20261009-MONEY-IN-WEIGHTED-OUTCOME-READBACK  
**Recommended classification:** BOTH GOVERNANCE + BLUE STATE / OPERATING RULE  
**Authority effect:** PROPOSAL ONLY — Governance decides promotion.

## Anomaly

AMX's active worker prompts correctly say that commercial outcomes should update weighting:
- bounce → contact/source reliability down;
- wrong person → routing correction;
- already solved → problem freshness down;
- rejection → fit/suppression update;
- positive buyer response → warm priority up;
- acceptance → conversion priority up;
- payment → strongest success evidence.

The current sweep cannot independently prove a complete causal path from a specific outcome event to a specific weight change to a changed subsequent selection.

Therefore the missing element is not another weighting philosophy. It is **causal readback / acceptance evidence**.

## Proposed rule

**NO OUTCOME-PROPAGATION RECEIPT → NO CLAIM THAT WEIGHTED LEARNING OCCURRED.**

For each material outcome that should affect future prioritization, preserve a compact receipt containing:

1. source event ID / thread / receipt;
2. opportunity/entity/source keys affected;
3. outcome class;
4. dimensions affected (contact quality, problem freshness, offer fit, geography, sector, source, route, price, etc.);
5. direction of change;
6. magnitude where the system uses explicit numeric weights, otherwise categorical effect;
7. confidence/evidence basis;
8. freshness/TTL where applicable;
9. before-state priority/weight snapshot sufficient for verification;
10. after-state priority/weight snapshot sufficient for verification;
11. next-selection consequence or explicit reason why ranking did not change;
12. preservation of diversity / anti-overfit controls.

Private chain-of-thought is not required or permitted by this proposal. The receipt contains decision-state evidence only.

## Commercial consequence

Without causal readback, the Matrix can repeatedly say it is learning while:
- stale contacts continue to be selected;
- losing offer patterns keep resurfacing;
- strong warm evidence fails to gain priority;
- downstream buyer outcomes never improve upstream discovery;
- a flat prompt assertion substitutes for demonstrated weighted continuation.

## Existing authority / conflict check

This proposal complements:
- MATRIX-03 durable cognition / weighted relationship continuity;
- Weighted Continuity Benchmark Integrity;
- FIRST BREATH FORX/iSCOPE/PRI feedback rules.

It does not replace them and does not prescribe universal fixed coefficients.

## Acceptance test

Demonstrate at least three real attributable outcome classes from live commercial evidence, for example:
- permanent bounce;
- explicit buyer rejection or wrong-person referral;
- substantive positive buyer response.

For each, independently read back:
**EVENT → WEIGHT/STATE UPDATE → NEXT SELECTION / PRIORITY CONSEQUENCE.**

PASS only if the effect survives the next runtime/continuation boundary.

## Anti-overfit rule

One outcome must not collapse global diversity or permanently encode a user/company-specific result as universal truth. Weight changes must remain reversible, scoped and evidence-sensitive.
