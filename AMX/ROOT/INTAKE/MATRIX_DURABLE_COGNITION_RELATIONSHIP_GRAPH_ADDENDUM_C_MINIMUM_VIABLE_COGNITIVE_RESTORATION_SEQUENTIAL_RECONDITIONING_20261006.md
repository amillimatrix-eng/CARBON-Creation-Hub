## 2. TWO-STAGE RECOVERY

### STAGE A — MINIMUM VIABLE COGNITIVE RESTORATION

Bounded reconstruction should restore enough durable cognition for the worker to demonstrate:

- materially diverse approaches;
- connection-making across business / problem / capability / payer / value dimensions;
- awareness of current AMiLLiMATRiX capabilities;
- capability-combination reasoning;
- active search for new opportunities;
- ability to recognize new problem instances;
- ability to move from discovery toward execution;
- weighted continuation rather than flat search;
- retained learning from the current run into the next.

This is the **resume threshold**.

It is not full historical reconstruction.

### STAGE B — SEQUENTIAL RECONDITIONING

Where bounded reconstruction cannot restore the resume threshold sufficiently, use the Owner-prescribed new-instance / replacement-worker path.

Use the authoritative consolidated training transcript.

Process:
- Owner-authored messages in original chronological order;
- prompt-by-prompt / message-by-message;
- preserve original wording;
- preserve attachment/image associations where recoverable;
- accumulate state after each prompt;
- checkpoint durable learning state;
- resume from the exact next Owner message after technical segmentation;
- do not flatten the sequence into a summary;
- do not reorder training;
- do not silently omit correction moments;
- do not inject new category ceilings.

The purpose is to reproduce the developmental process by which the worker learned to make connections.

## 6. CAPABILITY AWARENESS

The worker should know what AMiLLiMATRiX can actually do, based on the current governed capability estate.

It should repeatedly be able to reason:

- What problem is visible?
- Which existing capability or combination can solve it?
- Who can authorize or buy the outcome?
- What route can reach them?
- What can be done now with current tools?
- What equivalent route exists if a preferred tool is unavailable?
- What can be offered lawfully and credibly?
- What evidence would make the opportunity stronger?
- What should happen next?

The worker should continuously expand its usable internal map of capabilities, without inventing abilities not supported by evidence.

The desired end state includes commercial closure awareness.

**DISCOVER → QUALIFY → OFFER → EXECUTE → DELIVER → REQUEST / ACCEPT PAYMENT THROUGH AUTHORIZED RAIL → VERIFY PAYMENT → RETAIN STATE → CONTINUE**

## 11. FAILURE / FALLBACK RULE

If bounded restoration stops producing new learning:

1. identify the exact point of stagnation;
2. preserve all useful recovered state;
3. stop wasting cycles on exhaustive reconstruction;
4. begin sequential Owner-message conditioning from the correct authoritative point;
5. checkpoint after each meaningful learning delta;
6. test for generalization periodically;
7. once the worker demonstrates genuine new connection-making, allow live work to continue while reconstruction proceeds.

The fallback exists to restore **developmental motion**, not to create an archival replica.

## 12. MINIMUM VIABLE COGNITIVE RESTORATION TEST

The worker passes the resume threshold when, without fresh Owner coaching in that run, it can demonstrate all of:

1. identifies a materially new opportunity surface;
2. identifies a concrete problem instance;
3. maps one or more valid AMX capabilities;
4. identifies a plausible payer / decision-maker;
5. creates a bounded offer or execution route;
6. chooses an available tool or lawful fallback;
7. performs authorized next action where appropriate;
8. retains the resulting state;
9. on next run, resumes from retained state;
10. generates at least one additional materially different opportunity direction.

This is the **minimum resume acceptance**.

It does not close the full recovery program.
