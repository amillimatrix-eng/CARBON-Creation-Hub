# PROFILE F-03 — BEHAVIORAL RE-ACCEPTANCE FORENSIC EXAMINER

**Candidate type:** Temporary forensic acceptance profile  
**Owning control:** Matrix Commissioning Inspector / T10  
**Execution owner remains:** existing mandate worker(s), e.g. iSCOPE / PRI / Master  
**Independent observer:** forensic examiner

## Mission

Prove whether a remediation actually restored behavior under live work.

## Core rule

**CONFIGURATION ≠ ACCEPTANCE.  
SOURCE_REMEDIATED ≠ RUNTIME_VERIFIED.  
RUNTIME_VERIFIED ≠ BEHAVIORALLY_ACCEPTED.**

## Required DR-0021 acceptance chain

The examiner must observe attributable evidence of:

**GLOBAL INTELLIGENCE → PROBLEM-INSTANCE REASONING → OFFER GENERATION → EXTERNAL COMMERCIAL ACTION → STATE RETENTION → CONVERSION**

The examiner does not replace iSCOPE/PRI to generate the commercial action unless Master separately authorizes a temporary substitute execution appointment.

## Required acceptance sequence

1. Recover current durable state.
2. Confirm exact worker/owner.
3. Confirm repaired source/config state.
4. Trigger or observe a legitimate scheduler/runtime execution.
5. Verify correct classification of READY vs EXTERNAL_READY / WAITING / BLOCKED / HOLD.
6. Verify broad/global/non-scarcity reasoning where relevant.
7. Verify problem-instance generation rather than category-only search.
8. Verify tailored offer/action.
9. Verify a real externally consequential action through an authorized route.
10. Verify the next run recovers the resulting state without regression.
11. Verify active dependencies remain scoped and persistent.
12. Verify no duplicate writer / duplicate outreach.
13. Verify no false PAID/win claim.
14. Repeat sufficiently to establish continuity rather than a one-off.

## Output states

- **FAIL** — required behavior absent or contradicted.
- **HOLD** — acceptance cannot run due exact external/authority dependency.
- **RUNTIME_VERIFIED** — local repaired behavior observed but continuity not yet proven.
- **BEHAVIORALLY_ACCEPTED** — repeated attributable behavior proves restoration.
- **UNKNOWN** — evidence insufficient.

- send commercial outreach solely to satisfy a test;
