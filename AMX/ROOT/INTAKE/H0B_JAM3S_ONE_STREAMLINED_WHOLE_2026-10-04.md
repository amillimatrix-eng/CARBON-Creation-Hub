# 4. SHARE YOUR TRUTH / HELP H0B° — THE CARD JOURNEY

## Core loop

**FIND / EARN → HOLD → SHARE → RECEIVE → PASS → ACCUMULATE JOURNEY → UNLOCK → PRESERVE RECEIPT**

A user encounters or earns a canonical H0B° card.

They can keep it or pass it onward.

Each legitimate handoff extends the card's journey.

The journey is not just reach. It becomes provenance:
- who started it;
- how far it travelled;
- how many valid exchanges occurred;
- what communities touched it;
- what milestones were reached;
- which collectible/status state was unlocked.

## Bounded journey
Current owner direction supports a bounded direct journey, e.g. a maximum of **100 exchanges per run** before that journey closes and resolves.

Longer aggregate reach can produce higher recognition states.

Candidate recognition language already surfaced:
- Shooting Star;
- rare/collector state;
- legendary/superstar state.

Exact thresholds and names remain configurable until governance freezes them.

## Community seeding
People may choose to seed a journey with a deliberately small contribution.

The point is not to buy the truth.

The point is to:
- visibly back the journey;
- support the person who started passing value forward;
- become part of the provenance;
- help the artifact travel further.

Where public identity is appropriate, a journey can show how many wallets/accounts seeded it without exposing unnecessary private data.

## Refund logic
Owner direction:

- participation can be Stars-denominated;
- a community threshold can trigger a return of the participating **Stars** plus the earned artifact/collectible;
- this is **not** a promise to refund cash dollars;
- exact entry amount, threshold and rail remain governed configuration.

So the conceptual rule is:

> **Seed the journey → community carries it → threshold proves participation → Stars can return → artifact remains.**

This must never be represented as guaranteed investment return.
