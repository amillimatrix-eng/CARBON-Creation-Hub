## 7. CAPABILITY-ESTATE GOVERNANCE

FORX should classify capabilities into:

### TIER A — CURRENTLY EXPOSED / USABLE
Already present in the active tool environment.

### TIER B — APPROVED CANDIDATE / CONNECT WHEN MATERIAL
Available plugin whose capability materially fills a gap.

### TIER C — SENSITIVE / EXPLICIT GATE
Capability involving:
- credentials;
- money-out;
- legal consent;
- destructive action;
- highly sensitive personal data;
- protected external publication;
- irreversible action.

### TIER D — UNAVAILABLE
Not currently provisioned / disabled / not installable.

Missing Tier B/D capability must not become global Matrix idle if a lawful equivalent A/B/C fallback exists.
