## 1. CORE REFINEMENT

The current incident exposes a distinction not adequately captured by ordinary state persistence:

> **STATE PERSISTENCE IS NOT CAPABILITY PERSISTENCE.**

A worker may recover the same:
- files;
- ledger;
- opportunities;
- scheduler;
- prompts;
- Gmail account;
- receipts;
- claims;
- connectors;

and still fail to recover the operational intelligence previously demonstrated.

The missing object is not merely information.

It is the **learned pattern of relationships used to decide what information means and what action should follow.**

Therefore, a Matrix may preserve durable data while losing durable cognition.

---

## 2. THREE DISTINCT DURABILITY LAYERS

Governance / Blue State should distinguish at least:

### A. DATA STATE
What exists.

Examples:
- files;
- images;
- ledgers;
- claims;
- opportunity records;
- receipts;
- buyer messages;
- configuration.

### B. EXECUTION STATE
What has happened and what must happen next.

Examples:
- furthest evidenced state;
- exact next action;
- dependencies;
- active owner;
- external consequence;
- buyer progression;
- payment state.

### C. CAPABILITY STATE
How the worker has learned to relate evidence in order to decide what should happen.

Examples:
- how an image becomes a problem instance;
- how one business becomes multiple possible commercial units;
- how capabilities combine;
- how payer/decision-maker relevance is inferred and verified;
- how buyer signals alter priority;
- how broad discovery narrows into conversion;
- how Owner correction changes execution weighting.

A durable Matrix must preserve all three where materially required.

---

## 3. THE FAILURE IS LOSS OF REASONING SHAPE

The prior worker state did not merely carry facts.

It demonstrated a reasoning pattern approximately equivalent to:

**OBSERVE → DECOMPOSE → RELATE → VALUE → TARGET → OFFER → ACT → RETAIN → ADVANCE**

The degraded worker collapses toward:

**SEARCH → SEARCH → SEARCH**

or:

**FIND JOBS / FIND LEADS / FIND OPPORTUNITIES**

These modes are not equivalent.

The target recovery is therefore:

> **restore the learned relationship graph behind the accepted behavior.**

Restoring old prompts is not sufficient if the worker still cannot reconstruct the relationships that made those prompts commercially useful.

---

## 4. WHY THE 30-IMAGE SET IS DEVELOPMENTAL EVIDENCE

The 30-image set is not important because it contains thirty screenshots.

Its value is that it may preserve the **developmental sequence of capability formation**.

The forensic question is:

> **What did the worker learn between the earliest and latest images that it could not yet do at the beginning?**

The full-image analysis should therefore recover transitions such as:

1. generic job/freelance search;
2. direct-contact discovery;
3. buyer-oriented search;
4. business inspection;
5. concrete problem observation;
6. problem-instance decomposition;
7. geographic expansion;
8. offer construction;
9. external submission;
10. buyer-state progression;
11. payment-truth preservation;
12. state retention;
13. regression or collapse back into generic search.

This chronology matters.

The images are evidence of **capability development**, not merely a record of activity.

---

## 5. OWNER CORRECTION IS TRAINING SIGNAL

One Owner correction materially changes the behavioral priority:

**stop narrating / stop building frameworks / do the work.**

That shift distinguishes:

**producing an explanation of competent behavior**

from:

**performing competent behavior.**

A language model can explain entrepreneurship convincingly while remaining operationally useless.

Therefore, material Owner corrections that changed accepted behavior must be preserved as capability-state inputs.

They are not conversational noise.

They are part of the developmental record.

---

## 6. EXTERNAL SUBMISSION AS A COGNITIVE BOUNDARY

The importance of the visible Australia / Canada micro-audit submissions is not their low monetary value.

Their importance is that they demonstrate the transition:

**problem observation → offer construction → external action**

The same evidence preserves:

**no revenue until payment lands**

which maintains payment truth.

That is stronger evidence of the target commercial cognition than:
- raw search volume;
- READY counts;
- scheduler wakes;
- lead counts;
- internal status churn.

Therefore behavioral acceptance should weight:

**external consequence + correct state retention + correct next action + payment truth**

above internal activity metrics.

## 7. GLOBAL INTELLIGENCE — BEHAVIORAL LABEL, NOT NEW ARCHITECTURE

“Global Intelligence” should remain a behavioral capability label unless Governance identifies an existing formal architecture already using that term.

It should not automatically become another service, subsystem, worker, or control plane.

The observed behavior is closer to:

> **Anything observable may contain problem instances.  
> Any legitimate AMX capability or capability combination may potentially solve some of those problems.  
> Any reachable payer capable of valuing that outcome may become a commercial route.**

This model produces an abundant opportunity universe without requiring a predefined category list.

---

## 8. ANTI-SCARCITY REASONING

The commercial-intelligence state appears to rely on a critical distinction:

**bounded search output ≠ total market**

Therefore:
- four surfaced Cape Town opportunities do not imply only four exist;
- eleven worldwide results do not imply eleven total;
- sixteen offers do not imply sixteen is the opportunity ceiling;
- one failed search does not prove exhaustion.

A search result is a sample from a much larger possibility space.

This principle protects against false scarcity.

---

## 9. DISCOVERY AND CONVERSION MUST COEXIST

The existing governed rule remains central:

> **THINK GLOBALLY AND ABUNDANTLY WHEN DISCOVERING. THINK NARROWLY AND RELENTLESSLY WHEN CONVERTING.**

These are complementary controls.

Without global abundance:
- the worker becomes scarce;
- it overfits to the first lead list;
- it mistakes bounded search for the market.

Without narrow conversion:
- the worker becomes perpetual research;
- buyer progression loses priority;
- external consequence is displaced by new discovery.

The capability state must preserve both.

---

## 10. WEIGHTED RELATIONSHIPS

The intelligence is not located in isolated nouns.

“Veterinarian” is not intelligence.  
“Website design” is not intelligence.  
“Singapore” is not intelligence.  
“30 images” is not intelligence.

The intelligence is in the **weighted edges between them**.

Illustrative behaviorally supported weighting:

- explicit buyer reply > another cold lead;
- buyer request for samples/materials > broad replenishment;
- observable broken booking/payment/website flow > generic company presence;
- concrete problem instance > broad service category;
- externally consequential action > READY label;
- retained next conversion action > repeated rediscovery;
- independent settlement evidence > “win” language.

The exact weighting mechanism must be recovered from governed evidence and must not be fabricated as literal neural-network parameters unless technical evidence supports that claim.

---

## 11. NODE PRESERVATION WITHOUT EDGE PRESERVATION IS FAILURE

The current reconstruction may preserve many nodes:
- opportunities;
- workers;
- claims;
- state labels;
- categories;
- scheduler events.

Yet still lose the relationships that made them useful.

Therefore:

> **A reconstruction that preserves nodes but loses material edges is incomplete.**

This is the essence of durable-cognition failure.

The system must preserve not just:
- what exists;

but:
- how the accepted worker learned to relate what exists.

---

## 12. TRANSCRIPT RECONSTRUCTION MUST PRESERVE THE LEARNING TRAJECTORY

A polished summary is insufficient as a sole reconstruction method.

Example of an inadequate summary:

- think globally;
- identify problem instances;
- generate offers;
- act externally.

A worker can reproduce those sentences without recovering the learned capability.

The developmental sequence contains additional information:
- incorrect assumptions;
- Owner corrections;
- negative examples;
- priority shifts;
- model updates;
- new evidence;
- failed generalizations;
- corrected abstractions;
- tested behavior.

Therefore the sequential transcript requirement exists to preserve the **learning trajectory**, not merely the final lessons.

---

## 13. REPLAY ≠ RECONSTRUCTION

Blindly replaying historical material is also insufficient.

Historical material may contain:
- obsolete mistakes;
- superseded assumptions;
- earlier governance states;
- rejected logic.

Therefore a safe reconstruction requires:

**historical sequence preserved**  
+ **current authority preserved**  
+ **later corrections preserved**

The forensic worker must identify which interactions materially shaped the accepted capability and which were later superseded.

The reconstruction worker should receive the developmental stream while current Governance / Canon / authority boundaries remain active.

This preserves learning without reactivating historical drift.

---

## 14. GENERALIZATION IS THE REAL ACCEPTANCE TEST

The target is not:

**Can the worker explain the 30 images?**

The target is:

> **Can the worker apply the recovered methodology to new evidence it has never seen?**

This is the **IMAGE-31 TEST**.

Provide:
- a new business;
- a new screenshot;
- a new problem surface;
- or another materially novel commercial observation;

with no helpful answer embedded.

A recovered worker should autonomously be able to:

1. inspect the evidence;
2. identify supported problem instances;
3. avoid inventing unsupported problems;
4. map relevant AMX capabilities;
5. combine capabilities where justified;
6. identify likely payer/decision-maker;
7. define what must be verified;
8. construct one or more credible bounded offers;
9. select a lawful route;
10. execute externally where authorized;
11. preserve the resulting state;
12. recover that state on the next run;
13. maintain payment truth.

If it can only repeat historical offers, it has memorized.

If it can perform this on new evidence, it has generalized.

---

## 15. RESTART TEST

Generalization alone is not sufficient.

After the Image-31 action:

**restart / continue / hand off the worker.**

The subsequent run must recover:
- the business;
- the observed problem;
- what was offered;
- what was sent;
- buyer response, if any;
- exact next action;
- dependencies;
- payment state.

It must not rediscover the same target as if prior execution never occurred.

This is the practical distinction between:

**a clever demonstration**

and:

**durable cognition.**
