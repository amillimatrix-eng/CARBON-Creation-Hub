# AMilliMATRiX operating rules

- MODEL != MATRIX. ROOT INSTANCE != MATRIX. This repository is a control surface;
  CARBON° is the Creation Hub / Degree of Business, not the entire Matrix.
- Inspect CONTINUITY/, accepted receipts, current contracts, configuration and tests
  before changes. Resume from the furthest evidenced state. Source existence,
  ACTIVE/READY labels, schedules and heartbeats do not prove material execution.
- REUSE -> EXTEND -> TEST -> RECEIPT. No duplicate Matrix, Root, House, PRI, iSCOPE,
  Reaper or CARBON°. Root reconciles authority; OVERDRIVE transports/preserves/routes
  evidence. Critic verifies/falsifies. NotebookLM/provider output is advisory.
- Bounty Reaper owns the independent crypto bounty/reward lane. iSCOPE owns commercial
  discovery before handoff; PRI owns qualified commercial progression. The current
  commissioning directive corrects older Reaper subordination clauses; preserve
  those files as provenance, do not resume the superseded routing rule.
- Preserve capability and evidence; never silently discard or weaken either.
  UNKNOWN/HOLD beats invention. Record exact capability/gate, remediation and resume
  condition. Course corrections do not end an active job.
- Governed source/authority != mirror != backup != worker cache. Availability does
  not grant authority. Keep supersession and provenance through restores.
- No credentials, private evidence, commercial terms or raw worker output in this
  public repository. Credentials remain scoped, local, mode 0600, outside Git.
  Workers use explicit grants; no ambient shell, credentials, deployment, spending,
  signatures, outreach or mandate changes. Never log credential values.
- Encrypt recovery payloads and manifests; use a proven cryptographic library.
  Verify before promotion. Restore to a new target, compare hashes, issue a receipt;
  never overwrite live authority in a test. Test corruption and interruption.
- Lessons distinguish FACT/HYPOTHESIS/HEURISTIC/FAILURE_MODE/PROVEN_IMPROVEMENT.
  Version consequential changes, test them, require authorized promotion; learning
  cannot change a mandate or grant. Payout needs actual payment evidence.
- NO RECEIPT -> NO CLOSURE. Commit consequential changes, preserve newer remote
  state, publish through a review branch, and read back commit and receipts.
- BLACK is an existing execution worker. Keep one instance. Distinguish Linux
  systemd startup, WSL VM startup and Windows login/boot. Prior post-reboot receipts
  survive; full no-touch startup and new service installation require fresh proof.
